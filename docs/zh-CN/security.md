# 安全说明

[English](../en-US/security.md) · [文档首页](README.md)

本项目是本地开发工具，不是远程服务。

## 受保护的属性

- 原始 Figma 节点在策略和写入处理器的范围检查中均为只读。
- Proposal 身份会持久化在插件数据中，不能仅通过名称提供。
- Agent 提供的 ID 只表达编辑意图。复制根由插件解析，副本会脱离到 Page，并在显示隔离 Proposal 前核对源上下文指纹。
- 包括布局上下文在内的整个 Proposal 均可写，但写操作不能跨越其带标记的根节点。
- 第二个插件连接会被拒绝，不能驱逐当前活动连接。
- 已捕获的身份验证证明不能重复使用，因为每个连接都会获得新的服务器 nonce，并提供新的插件 nonce。
- 配对默认关闭。只有显式运行 `pair` 才会开启一个 120 秒会话，并且必须由用户核对六位 SAS 短码后才保存设备凭据。
- X25519 与 HKDF-SHA-256 为每个插件派生独立 token。token 不会通过 WebSocket 传输，并与 MCP Adapter 使用的 Daemon 凭据隔离。
- 长时间运行的文件输出受载荷和磁盘配额限制。
- 临时导出不会写入 agent 工作区或用户选择的项目路径。
- 入站设计素材只接受 Base64，在到达插件前经过格式和容量校验，且不会触发外部网络请求。
- DesignPlan 组件发现仅限当前页面；插件没有 `teamlibrary` 权限，也不会调用 Team Library 或 import-by-key API。
- 已有样式、变量和组件只读；新本地资源使用 `Agent/<Proposal>/...` 命名空间，失败时删除，成功后永久保留。

## 操作指南

- 使用 `devices list` 和 `devices revoke` 审计或移除已配对插件。撤销活动设备会立即断开连接。
- 不要通过代理或端口转发暴露 3900 端口。
- 仅在使用桥接工具期间保持 Figma 插件状态窗口打开。
- 将 Proposal 复制到生产稿前，先进行视觉审查。
- 用户要求修改历史记录时，请使用 Figma 原生 Undo。桥接工具只会在带锚点的写入边界内为刚刚失败的操作使用 undo；只读校验失败绝不会触发 undo。

## 明确不支持的目标

当前版本不包含任意脚本工具、源稿修改开关、通用删除、分离 Instance、Team Library 抓取、OAuth 流程、远程访问、多主机仲裁或协作同步。
